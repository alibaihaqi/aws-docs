# AWS Advanced

[Hub](https://alibaihaqi.github.io/learning-docs/) › AWS › Advanced

## What you'll build

You extend the intermediate Lambda + API Gateway dynamic site into a production-capable stack. You add a DynamoDB table for persistent data, Cognito authentication with a Lambda authorizer, Infrastructure as Code with CDK, local testing with SAM, CI/CD with CodePipeline, observability with CloudWatch, and production hardening with WAF and rate limiting.
